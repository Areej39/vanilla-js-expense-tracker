# Expense Tracker

A simple and responsive expense tracker application built with HTML, CSS, and Vanilla JavaScript. It allows users to track income, expenses, and balance dynamically while providing transaction management features such as editing and deleting entries.

## Features

- Add income and expense transactions
- Automatic balance calculation
- Real-time income and expense totals
- Edit existing transactions
- Cancel transaction editing
- Delete transactions
- Highlight currently edited transaction
- Dynamic transaction list updates
- Income and expense visual indicators
- Input validation
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

- Enter a description and amount.
- Use a positive amount for income.
- Use a negative amount for expenses.
- Click **Add Transaction** to create a new entry.
- Click **Edit** to modify an existing transaction.
- The selected transaction is highlighted while editing.
- Click **Update Transaction** to save changes.
- Click **Cancel Edit** to exit edit mode without saving.
- Click **Delete** to remove a transaction.
- Balance, income, and expense totals update automatically after every change.
